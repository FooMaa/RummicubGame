# Проверка сборки · 27 октября 2026

Окружение: Linux, JDK 17, Gradle Wrapper 8.4, Android SDK 34, Build Tools 34.0.0.

Проверено:

- `:core:test` — 10 тестов, включая 20 полных партий ботов с проверкой сохранения всех 106 фишек после каждого хода.
- `:server:test` — 5 интеграционных тестов: аккаунты и отзыв сессий, права комнат, сохранение после рестарта, отклонение неверных/повторных ходов, полная партия двух HTTP-клиентов и автономный ход серверного бота.
- `:app:lintDebug` — без замечаний.
- `:app:assembleDebug` — подписанный установочный APK; подпись подтверждена `apksigner verify`.
- `:app:assembleRelease` — сборка release без ключа (неподписанная, не включена в установочный артефакт).
- `:server:distZip` и `:server:installDist` — дистрибутив сервера; `/health` возвращает `{"status":"ok"}`.
- APK установлен и запущен на Android Emulator API 34, Pixel 5. Пройдены тренировка с ботом, сортировка подставки, открытие правил и возврат в сохранённую тренировку.
- Через Android UI выполнены регистрация, создание комнаты без таймера, добавление серверного бота, запуск партии, восстановление зашифрованной сессии и комнаты после принудительного завершения процесса, выход из комнаты. Сервер для этого теста запускался отдельно с временной БД на порту 18080.
- Проверены выбор фишки, создание чернового ряда, отклонение неправильной комбинации, отмена черновика и поворот экрана с сохранением партии. В AndroidRuntime нет зарегистрированных падений приложения во время этих сценариев.

Артефакты локальной проверки находятся в игнорируемой Git папке `artifacts/`: APK, ZIP сервера, SHA-256 и реальные снимки экрана эмулятора. Код и Gradle Wrapper находятся в репозитории; APK пересоздаётся скриптом `scripts/build-apk.sh` или GitHub Actions.

Не выполнялись: запуск workflow на удалённом GitHub (изменения ещё не отправлены), публикация сервера в интернете, установка на физический телефон, сборка Docker-образа (в окружении нет доступа к Docker daemon и установленного Compose plugin), подпись собственным release-ключом. Эти проверки не выдаются за выполненные.
