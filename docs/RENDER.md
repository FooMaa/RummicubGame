# Альтернатива: Render Free + существующая YDB

Конфигурация подготовлена в `render.yaml`, но сервис на Render ещё не создан и не проверен. Render размещает этот вариант во Франкфурте, за пределами России.

Существующий Dockerfile запускает Java-сервер. При заданной `YDB_CONNECTION_STRING` он использует облачное транзакционное хранение снимка; локальный файл SQLite служит временным кэшем. Поэтому исчезновение локального диска Render не должно удалять аккаунты и партии. Этот режим уже проверен локально с настоящей YDB.

## Перед развёртыванием

1. Зарегистрировать Render и подключить GitHub-репозиторий с актуальным кодом.
2. Включить blueprint из `render.yaml`, оставив тариф Free.
3. Задать `YDB_CONNECTION_STRING` для созданной базы.
4. Создать отдельный сервисный аккаунт для Render с доступом только к базе игры. Хранить его авторизованный ключ в Render Secret File `rummiclub-ydb-key.json`, доступном по `/etc/secrets/rummiclub-ydb-key.json`. Ключ не коммитится в Git и не отправляется в чат. Его создание и передачу на Render нужно согласовать перед выполнением.
5. После запуска проверить `/health`, регистрацию, комнату с ботом и сохранение при перезапуске, затем пересобрать APK с новым HTTPS-адресом.

## Ограничения

- Render Free засыпает после 15 минут без запросов. Возобновление обычно занимает около минуты. Первый запрос приложения может завершиться по таймауту; перед передачей игрокам нужен тест этого сценария и соответствующая обработка холодного старта клиентом.
- Постоянный диск и бесплатный PostgreSQL Render не используются. База остаётся в YDB с её отдельными бесплатными квотами.
- Нулевая стоимость не гарантируется сверх квот. Render может приостановить бесплатный сервис при необычно большом исходящем трафике, включая обращения к внешней базе. Нужен замер потребления небольшой реальной партии.
- Проблема Cloud Functions обходится переносом вычислений на Render. Доступность YDB остаётся зависимостью этой схемы.

Источники: [ограничения Render Free](https://render.com/docs/free), [бесплатные квоты Yandex Cloud](https://yandex.cloud/ru/docs/billing/concepts/serverless-free-tier).
