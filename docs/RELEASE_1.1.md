# Руммикуб 1.1.0 · 30 октября 2026

## Изменения

- Подставка, панель действий и таймер закреплены снизу; общий стол прокручивается отдельно. В горизонтальной ориентации список участников сжат до одной строки, чтобы оставить место для рядов.
- Плюсы слева и справа у каждого ряда, новый ряд под столом. Тапы остаются альтернативой перетаскиванию.
- Удержание фишки запускает drag & drop. Левая/правая половина целевой фишки задаёт вставку перед/после неё; зелёная линия показывает позицию. Выбранную группу можно переносить вместе. На подставку возвращаются только свои фишки.
- Кнопка со стрелкой назад восстанавливает стол на начало текущего хода. Черновик сброса имеет новую версию, поэтому запоздавшая сетевая запись не возвращает отменённые изменения.
- По таймауту подтверждаются правильные комбинации. В неполном ряду выбирается наибольшее допустимое упорядоченное подмножество новых фишек с сохранением всех старых. Связанные незавершённые перестройки восстанавливаются целиком; независимые правильные ряды сохраняются. Первый выход требует 30 очков. При отсутствии допустимого добавления берётся одна фишка.
- Черновик хранится на сервере и виден только владельцу хода. Учитывается последний полученный сервером черновик; под кнопками отображается статус сохранения. Нет автоматического повтора игровых POST-запросов.
- Таймер жёлтый за 20 секунд и красный за 10. Звук/вибрация при смене хода, отдельное предупреждение на 10 секундах своего хода; события не повторяются от перерисовок и опросов. В настройках доступны отключения.
- Иконки, подсказки при удержании, справка по кнопкам через «?». Меню использует иконки с поясняющими подписями; игровые кнопки — без текста.
- Видимое имя — «Руммикуб». Application ID, данные приложения, адрес сервера и постоянный ключ подписи сохранены для обновления поверх предыдущей версии.

## Проверка

- 40 тестов прошли: 17 ядра, 9 сервера, 14 клиента. Два отдельных live-теста по умолчанию пропускаются.
- В ядре проверены частичное подтверждение, сохранность всех 106 фишек, первый выход, победа и счёт, джокеры, 80 неполных смешанных черновиков, отбрасывание старых версий, вставка в начало/конец/середину.
- Сервер проверен двумя экземплярами с общим хранилищем: приватность и восстановление черновика, отказ чужой фишки, завершение по дедлайну и отказ повторной просроченной команды.
- Android Lint прошёл. [GitHub Actions для кода релиза](https://github.com/FooMaa/RummicubGame/actions/runs/41066790816) завершился успешно.
- Android Emulator API 34: 12 UI-проверок прошли, включая настоящее перетаскивание касаниями, возврат на подставку, сброс, фиксированный таймер при прокрутке, цветовые границы и видимость целого ряда в landscape. Скриншоты сохраняются в `artifacts/ui/`.
- Тестовый эмулятор не заменяет проверку ощущаемой громкости и вибрации на физическом телефоне.

Повтор UI-проверки на одноразовом эмуляторе:

```bash
JAVA_HOME=/path/to/jdk17 ANDROID_SERIAL=emulator-5556 ./scripts/verify-ui.sh
```

На Render дополнительно прошёл сквозной тест с настоящим 60-секундным таймером, двумя игроками и ботом: приватный черновик, сброс, старая версия, частичное подтверждение. Тестовые данные очищены. Подписанный APK установлен поверх release 1.0.4 и запущен на эмуляторе; подпись совпадает.

Сетевая часть таймаута требует сервер с `apiVersion=2` в `/health`. Обновляйте сервер перед выдачей APK.
