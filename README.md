# Rummi Club · Android

Нативная игра по классическим правилам руммикуба: Android-клиент, общее игровое ядро, сервер и автоматическая сборка установочного APK. Интерфейс на русском, Android 8.0+ (API 26).

## Возможности

- Тренировка без интернета с 1–3 ботами, сохранение партии на устройстве.
- Регистрация по имени и паролю, вход на другом устройстве.
- Приватные комнаты на 2–4 участника по шестизначному коду.
- Хозяин добавляет и убирает ботов в комнате перед стартом, запускает повторную партию.
- Серверные боты и автоматическая замена вышедшего человека ботом.
- Общий стол: создание рядов, добавление, разбиение и перенос фишек, джокеры, отмена черновика, проверка первого выхода.
- Таймер 60/120 секунд или без ограничения; сохранение комнат в SQLite и переподключение.
- Подсчёт очков, окончание партии при пустой подставке или круге пропусков с пустым банком.
- Крупные фишки, сортировка, дополнительные точки для различения цветов.

## Быстро получить APK

Нужны JDK **17**, Android SDK Platform 34 и Build Tools 34.0.0. В Android Studio откройте корень проекта и установите SDK через SDK Manager. Путь к SDK задаётся через `ANDROID_HOME` или файл `local.properties` с `sdk.dir=/your/android/sdk`.

```bash
./scripts/build-apk.sh
adb install -r artifacts/RummiClub-debug.apk
```

На Windows: `gradlew.bat :core:test :server:test :app:assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

APK уже включает игру с ботами и запускается без сервера. Для сети нужно запустить сервер и указать его адрес в настройках приложения.

## Автоматическая сборка

Workflow [android.yml](.github/workflows/android.yml) запускается при push, pull request и вручную. Он проверяет ядро и API, запускает Android Lint, собирает APK и сервер. В GitHub откройте **Actions → Android APK and server checks → успешный запуск → Artifacts → RummiClub-Android-APK**. Распакуйте архив и установите `RummiClub-debug.apk` на телефон.

Без секретов сборка выдаёт подписанный debug APK. Его можно установить, разрешив установку из выбранного файлового менеджера. Debug-ключ на новом runner может отличаться: для обновления между такими сборками может потребоваться удаление старого приложения; локальная тренировка при этом удалится. Для постоянного ключа используйте release-сборку.

Перед выдачей APK workflow проверяет целостность ZIP, подпись и выравнивание пакета. Локально эти проверки запускаются командой `./scripts/verify-apk.sh artifacts/RummiClub-debug.apk`. Если телефон сообщает о проблеме с файлом, сравните его SHA-256 с `SHA256SUMS` из того же архива сборки. Точный код отказа можно получить через `adb install --no-incremental -r artifacts/RummiClub-debug.apk`; по одному тексту системного диалога нельзя отличить повреждение загрузки, конфликт подписей и ограничения установщика.

Необязательная repository variable `RUMMI_SERVER_URL=https://game.example.com` задаёт адрес по умолчанию. Его также можно менять в приложении.

Для подписанного release APK добавьте GitHub Secrets:

| Secret | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | JKS-файл, закодированный в Base64 |
| `ANDROID_KEYSTORE_PASSWORD` | Пароль хранилища |
| `ANDROID_KEY_ALIAS` | Псевдоним ключа |
| `ANDROID_KEY_PASSWORD` | Пароль ключа |

Секреты не нужны для debug. Release использует только HTTPS. Без секретов неподписанный release не выдаётся за установочный. Workflow подготовлен в репозитории; первый запуск в GitHub произойдёт после push.

## Сетевая игра в домашней сети

```bash
./gradlew :server:run
```

Сервер слушает порт 8080. На обоих телефонах в настройках укажите `http://IP_КОМПЬЮТЕРА:8080`, например `http://192.168.1.20:8080`. Телефоны должны быть в одной сети с компьютером, порт должен быть доступен. Для Android Emulator адрес хоста — `http://10.0.2.2:8080` (или `adb reverse tcp:8080 tcp:8080` и `http://127.0.0.1:8080`). HTTP разрешён только в debug APK.

1. Зарегистрируйтесь на каждом устройстве под разными именами.
2. Один игрок создаёт комнату и отправляет её код друзьям.
3. Остальные выбирают «Войти по коду».
4. Хозяин при желании добавляет ботов и начинает игру.

Кнопка «Моя текущая комната» возвращает в партию после закрытия приложения. При кратком обрыве связи клиент автоматически повторяет запросы состояния. «В меню» не означает выход из партии; сетевой таймер продолжает идти. «Покинуть комнату» передаёт место боту.

## Сервер в интернете

Для Yandex Cloud подготовлен отдельный вариант на Cloud Functions + YDB без постоянно работающей ВМ. Состояние развёртывания, ограничения небольшой установки и команды повторной публикации: [YANDEX_CLOUD.md](docs/YANDEX_CLOUD.md). Публичная проверка облачной функции пока не прошла; статус ACTIVE ресурса сам по себе не подтверждает работу API.

Нужны Linux-сервер с Docker Compose, домен с A/AAAA-записью на этот сервер и открытые порты 80/443.

```bash
cp .env.example .env
# Укажите свой домен в RUMMI_DOMAIN внутри .env
docker compose up -d --build
curl https://your-domain.example/health
```

Caddy получает TLS-сертификат. В приложении укажите `https://your-domain.example`. SQLite находится в постоянном volume `game-data`; не удаляйте его при обновлении. Для резервной копии используйте SQLite backup API или остановите сервер и копируйте весь volume, включая WAL-файлы. Образ сервера запускается от непривилегированного пользователя.

Вне Docker: `./gradlew :server:installDist`, затем `server/build/install/server/bin/server`. Переменные: `PORT` (8080), `DATABASE_PATH` (`data/rummiclub.db`). ZIP-дистрибутив сервера требует Java 17.

## Управление столом

Нажмите несколько фишек в нужном порядке. «Новый ряд» создаёт комбинацию, `+` справа от существующего ряда добавляет выбранные фишки. Долгое нажатие на фишку в ряду вставляет выбранные **перед ней**. Так можно перестраивать весь стол. Красная подпись обозначает незавершённый ряд. Сервер принимает только полностью правильный стол.

«Вернуть выбранные на подставку» возвращает только ваши фишки из черновика. «Отменить ход» восстанавливает стол на начало хода. «Подтвердить ход» отправляет весь ход. Взятие из банка сразу заканчивает ход.

## Устройство проекта и проверки

| Модуль | Назначение |
|---|---|
| `core` | Чистая Java 17: правила, состояние, бот, безопасное представление комнаты |
| `app` | Нативный Android UI, локальные партии, HTTPS-клиент, Android Keystore |
| `server` | Java HTTP API, SQLite, аккаунты, комнаты, таймеры и боты |

```bash
./gradlew :core:test :server:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Тесты проверяют комбинации/джокеры, первый выход, перестройку стола, сохранение всех 106 фишек в полных партиях ботов, очки, таймер, права участников, скрытые руки, отзыв сессий и восстановление сервера. Подробнее: [архитектура](docs/ARCHITECTURE.md), [API](docs/API.md), [вариант правил](docs/RULES.md).

Бот ищет непересекающиеся комбинации в своей руке и расширяет ряды на столе; произвольные глобальные перестройки он не решает. Сервер рассчитан на один процесс и небольшие компании. Бесплатный сервер: https://rummiclub.onrender.com; настройки и ограничения описаны в [инструкции Render](docs/RENDER.md). Ключ release-подписи хранится отдельно от репозитория. Нет подтверждения email, восстановления пароля, рейтингов и матчмейкинга. Это независимая реализация; название и графические материалы официальной игры не используются как бренд приложения.
